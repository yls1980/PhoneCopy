# PhoneCopy

PhoneCopy — двухпанельный файловый менеджер для Windows, написанный на C# и WPF. Слева файлы Android-телефона или USB-камеры, справа файлы компьютера.

## Скачать

[Готовая сборка для Windows x64](https://github.com/yls1980/PhoneCopy/releases/latest/download/PhoneCopy-win-x64.zip) — распакуйте архив и запустите `PhoneCopy.exe`. Установка .NET не требуется.

## Возможности

- Копирование и перенос файлов и папок в обе стороны.
- Android через MTP без отладки по USB. ADB доступен как дополнительный режим.
- Камеры и карты памяти, которые Windows показывает как USB-диск. Можно выбрать диск или папку вручную.
- Множественный выбор, сортировка по имени, размеру и дате, рекурсивная обработка папок.
- Диалог при совпадении имён во время переноса: заменить, сохранить оба, пропустить или отменить.
- Размер текущего файла, число обработанных и оставшихся файлов, отмена операции и журнал ошибок.

## Как пользоваться

1. Подключите устройство по USB. На Android разблокируйте экран и выберите режим «Передача файлов». Для USB-камеры дождитесь появления диска в Проводнике Windows.
2. В списке сверху выберите устройство. Если камера видна в Проводнике, но отсутствует в списке, нажмите «Выбрать диск/папку…».
3. Откройте папки слева и справа. Двойной щелчок открывает папку; Ctrl и Shift помогают выделить несколько файлов; щелчок по заголовку сортирует список.
4. Выделите файлы в панели источника и нажмите «Копировать» или «Перенести» в нужную сторону.

У DJI Osmo Action 5 Pro записи на карте памяти доступны через диск `SD_Card`, обычно в папке `DCIM`. Буква диска может меняться при переподключении.

**Копирование сохраняет исходные файлы.** При переносе приложение сначала записывает файл и проверяет размер копии, затем удаляет исходник. Если удаление не удалось, обе копии остаются, а ошибка отображается в окне. При замене старая версия назначения временно сохраняется как резервная копия. Размер проверяется для каждого файла; полная проверка по хешу при обычном переносе не выполняется.

Ошибки сохраняются в `%LOCALAPPDATA%\PhoneCopy\Logs`. Если MTP возвращает `0x800700AA` или `0x80004005`, проверьте режим USB, оставьте телефон разблокированным и переподключите его. Доступность содержимого зависит от Windows и самого устройства.

## Сборка

Нужны Windows x64 и .NET 7 SDK. Готовый автономный EXE не требует установленного .NET.

```powershell
dotnet build .\PhoneCopy\PhoneCopy.csproj -c Release
dotnet publish .\PhoneCopy\PhoneCopy.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o .\dist
```

Проекты:

| Путь | Назначение |
| --- | --- |
| `PhoneCopy/` | WPF-приложение |
| `PhoneProbe/` | Диагностика доступности MTP-устройств |
| `PhoneCopy.IntegrationTests/` | Проверки подсчёта и локального копирования; полный сценарий с телефоном создаёт тестовый файл на устройстве |

Безопасные проверки без изменения подключённого устройства:

```powershell
dotnet run --project .\PhoneCopy.IntegrationTests\PhoneCopy.IntegrationTests.csproj -c Release -- --count-smoke
dotnet run --project .\PhoneCopy.IntegrationTests\PhoneCopy.IntegrationTests.csproj -c Release -- --local-device-smoke
```

## Проверено

- На DJI Osmo Action 5 Pro приложение открыло SD-карту и показало видео. Тестовый MP4 скопирован на компьютер; SHA-256 источника и копии совпали, оригинал сохранился на карте.
- Локальные проверки прошли для копирования папки, пропуска совпадающего файла, переноса с заменой и защиты от совпадающих путей.
- Чтение через MTP на Android зависит от устройства: некоторые файлы могут возвращать ошибки Windows Portable Devices. Перенос с удалением оригиналов на самой DJI не запускался.

MTP реализован с помощью [MediaDevices 1.10.0](https://www.nuget.org/packages/MediaDevices/1.10.0). Лицензия этой зависимости приведена в [licenses/MediaDevices-MIT.txt](licenses/MediaDevices-MIT.txt).
